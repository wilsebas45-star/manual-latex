# 📘 Manual de LaTeX: Guía Paso a Paso

¡Bienvenido a mi repositorio oficial! Aquí comparto la versión compilada de mi guía completa sobre composición tipográfica en LaTeX.

## 🚀 ¿Qué encontrarás en este manual?
- Introducción a la filosofía de marcado lógico e historia de TeX / LaTeX.
- Manejo avanzado de texto, tipografía, guiones y colores.
- Tablas complejas, inserción de imágenes y gestión óptima de objetos flotantes (FIFO).
- Composición de matemáticas avanzadas, física (`siunitx`, `physics`) y química (`chemfig`, `mhchem`).
- Programación de gráficos vectoriales directos con **TikZ** y el entorno clásico `picture`.
- Creación de presentaciones profesionales con la clase **Beamer**.
- Gestión bibliográfica con BibTeX y compilación modular para proyectos grandes.
